# Arkiv — vilseledande statusrapporter

Filerna i den här katalogen är **arkiverade** därför att de påstår saker som inte stämde
när de skrevs: "100 % pass", "produktionsklart", "12/12 moduler klara" — samtidigt som
`npm run build` misslyckades med 12 fel, ingen testsvit kunde köra, tenant-isoleringen
var bruten och alla OCR-nummer var ogiltiga.

Se `GRANSKNING_OCH_OMSTARTSPLAN.md` i repo-roten för den fullständiga granskningen och
`KICKOFF_NYSESSION.md` för reglerna som gäller för ombyggnaden.

**Lita inte på innehållet i de här filerna som statusbeskrivning.** De behålls enbart
som historik och som exempel på varför regeln "inget påstående om status utan körd,
inklistrad bevisning" finns.
