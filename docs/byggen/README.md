# Byggjournaler (BMAD)

En fil per gront CTO-bygge: mal, sjalvbarande kravspec (med KALLA och ARKITEKTUR), utfall, granskningsdom och modellkedja. Skrivs automatiskt av CTO-motorn fore merge. Detta ar minnet UTANFOR sessionen — nasta kravstallare laser har vad som redan gjorts och varfor. Davids krav 17/8.
